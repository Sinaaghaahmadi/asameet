## ۱. اصول

| اصل | معنی در طراحی |
|---|---|
| محتوا قهرمان است | صفحات کاری (چت، جلسه، کلاس، مدیریت) ساکت‌اند: زمینهٔ مه، مرزهای کم‌رنگ، سبزآبی فقط برای عمل اصلی و حالت فعال. شیشه و عمق سه‌بعدی مال معرفی و آنبوردینگ است. |
| تلگرام‌وار، سازمانی | روانی تلگرام (حباب نامتقارن، تیک‌ها، فهرست با پیش‌نمایش، پوشه‌ها) + لایهٔ سازمانی (نقش‌ها، سازمان‌ها، جلسه، کلاس، صورت‌جلسه). |
| راست‌به‌چپ درجه‌یک | همه‌چیز با `start/end`؛ آینه‌شدن جهت‌دارها؛ اعداد فارسی؛ متن دوزبانه ایزوله. |
| یک رنگ سیگنال | زعفران فقط برای دستیار، تصمیم/اقدام و ضبط — حداکثر یک عنصر در هر نما. |
| سکون خوانا | هیچ محتوایی پشت انیمیشن نیست؛ اسکلت بارگذاری شکل نهایی را دارد. |

## ۳. چیدمان اپ

دسکتاپ: ریل ۶۸px (دریای عمیق) + فهرست ۳۰۰–۳۴۰px + محتوا (+ پنل راست اختیاری).
تبلت: ریل + فهرست؛ محتوا فهرست را کنار می‌زند. موبایل: تب‌بار پایین (چت‌ها، تماس‌ها، جلسات،
کلاس‌ها، منو)؛ ورود به چت، فهرست را جایگزین می‌کند. تراکم پیش‌فرض ردیف ۶۸px، فشرده ۵۶px.
پهنای حباب ≤ ۷۵٪ ستون و حداکثر ۵۶۰px.

## ۵. حالت‌ها

هر فهرست: اسکلت (شکل نهایی)، خالی (یک جمله + عمل بعدی)، خطا (چه شد + چه می‌شود).
آفلاین = نوار باریک کهربایی بالای نما؛ پیام‌ها با آیکون ساعت صف می‌شوند. حساب مسدود =
توضیح روشن + مسیر تماس. محدودیت ورود = شمارش معکوس.

## ۶. راست‌به‌چپ و چندزبانه

جهت از زبان (fa, ar = RTL). آیکون‌های جهت‌دار `rtl:-scale-x-100`. حباب خودی همیشه end.
فیلدهای لاتین `dir="ltr"`. زبان در قدم اول آنبوردینگ انتخاب می‌شود؛ ۵ زبان.

## ۷. دسترس‌پذیری

کنتراست ≥ 4.5:1 (متن روی سبزآبی = teal-700)؛ `aria-label` روی دکمه‌های آیکونی؛ فوکوس ۲px سبزآبی؛
pinch-zoom آزاد؛ حداقل متن ۱۲px؛ کاهش حرکت؛ حالت‌های ضبط/تماس با آیکون + متن، نه فقط رنگ.
