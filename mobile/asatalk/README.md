# Asatalk — iOS & Android (React Native / Expo)

اپ نیتیو آساتاک. همان بک‌اند وب (`/api/*` روی asameet.vercel.app و دیتابیس Supabase) را مصرف می‌کند؛ نشست همان کوکی httpOnly است که cookie jar نیتیو نگه می‌دارد، پس هیچ تغییری در احراز هویت سرور لازم نیست.

## اجرا

```bash
cd mobile/asatalk
npm install
npx expo prebuild            # یک‌بار: پوشه‌های ios/ و android/ را می‌سازد
npx expo run:android         # یا: npx expo run:ios (فقط روی macOS)
```

`react-native-webrtc` و `react-native-incall-manager` کد نیتیو دارند، پس **Expo Go کار نمی‌کند** — یا `expo run:*` یا یک dev client / بیلد EAS لازم است.

## بیلد فروشگاهی (EAS)

```bash
npm i -g eas-cli && eas login
eas init                     # projectId را داخل app.json می‌نویسد (برای پوش لازم است)
eas build -p android --profile production
eas build -p ios --profile production
```

## متغیرها

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `EXPO_PUBLIC_API_URL` | `https://asameet.vercel.app` | ریشهٔ بک‌اند |
| `EXPO_PUBLIC_TURN_URL/USER/PASS` | — | رله‌ی TURN برای تماس بین شبکه‌های متفاوت |

## چه چیزی هست

- ورود با شماره/ایمیل + کد، یا نام کاربری/رمز؛ تأیید ورودِ QR دستگاه دیگر با دوربین
- فهرست گفت‌وگوها با پوشه‌ها، پین/بی‌صدا/حذف با نگه‌داشتن
- گفت‌وگو: پیام من راست، طرف مقابل چپ؛ نگه‌داشتن = منو + ری‌اکشن؛ کشیدن = ریپلای؛ عکس/ویدئو از گالری یا دوربین؛ پیام صوتی با نگه‌داشتن میکروفون؛ ویرایش/حذف/سنجاق
- تماس صوتی و تصویری ۱:۱ و گروهی (mesh) روی همان سیگنالینگ وب، پس گوشی و مرورگر با هم تماس می‌گیرند
- حضور دقیق (آنلاین فقط وقتی اپ جلو است)، پوش نوتیفیکیشن پیام و تماس از طریق Expo Push
- تنظیمات: پروفایل، اعلان‌ها، پوسته و رنگ، زبان (فارسی/انگلیسی با RTL)، دستگاه‌ها

## چه چیزی نیست (هنوز)

کانال‌سازی، نظرسنجی/موقعیت/مخاطب، استیکرها، فوروارد، جستجوی پیام، اشتراک صفحه در تماس. همهٔ این‌ها API آماده دارند و فقط UI می‌خواهند.
