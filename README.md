# آساتاک | Asatalk

**پیام‌رسان و بستر تماس صوتی و تصویری** — سریع، شیشه‌ای، فارسی و RTL از پایه.

آساتاک عضو خانوادهٔ برند «آسا» است و روی همان دیتابیس آسامیت کار می‌کند، اما یک اپ کاملاً مستقل با استقرار جداگانه است.

```
Next.js 16 (App Router) · TypeScript · Tailwind 4 · Framer Motion
Zustand · TanStack Query · Radix · Supabase (Postgres) · WebRTC
```

## امکانات

- **ورود**: انتخاب زبان → اسپلش → شماره موبایل یا ایمیل با کد یک‌بارمصرف → پروفایل → اجازهٔ اعلان و میکروفون/دوربین (ورود با نام کاربری و رمز هم پشتیبانی می‌شود)
- **پیام‌رسانی**: چت خصوصی، گروه، کانال؛ متن، عکس، فایل، ویدئو، پیام صوتی با شکل موج، پیام ویدئویی دایره‌ای، استیکر، نظرسنجی، موقعیت مکانی، مخاطب
- پاسخ، فوروارد، ویرایش، حذف، سنجاق، واکنش، انتخاب چندتایی، @منشن، جستجو
- **وضعیت ۲۴ ساعته** (یادداشت روی آواتار)، بایگانی، پوشه‌های چت، پیش‌نویس
- **تماس**: صوتی و تصویری یک‌به‌یک با WebRTC، اشتراک صفحه، پنجرهٔ شناور، تاریخچهٔ تماس
- **چند حساب** (تا ۵ حساب هم‌زمان)، قفل پین، تم اختصاصی هر گفت‌وگو، پنج زبان (fa/en/fr/de/ar)

## اجرا

```bash
npm install
npm run dev          # http://localhost:3000
npm run build && npm start
```

بدون هیچ متغیر محیطی هم بالا می‌آید و به دیتابیس مشترک وصل می‌شود. برای استقرار واقعی `.env.example` را ببینید — مهم‌ترین‌ها:

| متغیر | چرا لازم است |
| --- | --- |
| `ASATALK_OTP_WEBHOOK_URL` | ارسال واقعی کد ورود با پیامک/ایمیل. بدون آن کد در حالت آزمایشی روی صفحه نمایش داده می‌شود. |
| `NEXT_PUBLIC_TURN_URL` / `_USER` / `_PASS` | تماس بین دو شبکهٔ متفاوت. بدون TURN فقط تماس داخل یک شبکه برقرار می‌شود. |

## معماری

- تمام دسترسی به داده از طریق توابع `public.api_*` در Postgres (SECURITY DEFINER) انجام می‌شود؛ جدول‌ها در اسکیمای خصوصی `app` هستند و کلاینت هیچ‌وقت مستقیم به آن‌ها دست نمی‌زند.
- نشست، کوکی httpOnly است؛ چند حساب با فهرست توکن‌ها در کوکی جداگانه.
- سیگنالینگ تماس از طریق صندوق پیام دیتابیس (`api_call_signal` / `api_call_poll`) — بدون سرویس بلادرنگ اضافه.
- رسانه‌ها base64 در جدول `app.media` و از مسیر `/api/media/[id]` سرو می‌شوند (سقف ۳ مگابایت).

```
src/app/            صفحهٔ اصلی (اپ) + /join/[ref] + مسیرهای /api
src/components/asatalk/   کل رابط کاربری آساتاک
src/lib/talk/       کلاینت API، رسانه، WebRTC، صداها، فرمت‌ها
src/lib/server/     کلاینت RPC سمت سرور + کوکی نشست
supabase/migrations/  اسکیمای دیتابیس (۰۰۰۱ تا ۰۰۰۵)
mobile/asatalk/     پوستهٔ اندروید (Capacitor)
docs/               مستندات محصول، دیزاین سیستم و برندبوک
```
